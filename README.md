# monah.me

The personal landing page at the root domain. Plain HTML and one stylesheet,
served by GitHub Pages. Edit, commit, push, live in about a minute.

`lumagarden.monah.me` is a **separate** repository (`Monah84/luma-garden`),
because a GitHub Pages site can only carry one custom domain.

## DNS

The root domain points here with an ALIAS record. Mail is unaffected: MX
records live on the same name but are a different record type, and the Google
Workspace verification TXT is untouched.
